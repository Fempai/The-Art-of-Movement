# Personalized model pipeline

Use approved reference images to commission or model a skinned humanoid GLB with embedded textures. Keep personal photos outside the public repository. Import the local GLB through the Studio, review the rig mapping report and usable animation clips, then compare front, side, back, and dance playback against approved references. The appearance JSON controls only the prototype. Imported models are not automatically modified. Actual likeness and device acceptance require review.
