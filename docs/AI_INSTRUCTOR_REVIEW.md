# AI Instructor Assessment Contract (Draft)

## Intent
Every graded assessment will be generated by the personalized AI instructor from submitted movement video, not from self-rated scores. The learner may also make their own judgments; their expertise does not change the need to label AI feedback as AI-generated.

## Status
This document specifies the integration contract. **No model, video upload, or grading API is connected yet.** The browser-only review form stores text request drafts; video stays on the device.

## Required review output
- Submission ID, video ID, skill and discipline, capture angle(s), review timestamp and model/version
- Evidence quality: adequate, partial, inadequate; missing views and confidence limitations
- Timestamped observations grounded in visible movement, not speculative diagnoses
- Five rubric dimensions scored 1–4: alignment/control, balance, coordination/timing, repeatability, skill-specific technique
- Provisional proficiency: Foundations, Developing Beginner, Intermediate Beginner, Intermediate, Advanced, Artistry
- Top two strengths, top three correctable issues, and a short practice prescription with sets/repetitions or timed drills
- Clear next-level criteria and whether footage is sufficient for a new evaluation
- Review status: queued, processing, needs_better_footage, reviewed, or failed
- For high-risk aerials, back handsprings, walkovers, deep contortion: AI cannot provide physical safety clearance; qualified in-person supervision remains necessary

## Security and implementation plan
1. Use existing Life OS Supabase Auth identity. Verify RLS and private media bucket access before writing.
2. Upload videos directly to private object storage with user-scoped paths and signed read URLs; never publish signed URLs or service-role keys in GitHub Pages.
3. Route requests through a protected server-side function that checks the authenticated user owns the submission, calls a vision-capable model/service with video-frame sampling, and stores its versioned output. Never call paid AI APIs directly from public browser JavaScript with secret keys.
4. Enforce idempotency, file size and duration limits, MIME validation, review rate limits, and safe retry behavior.
5. Provide review transparency and a learner dispute/correction button. Never label AI grading as human-verified.
6. Require consent for any media use and a deletion workflow that removes both stored video and derivative thumbnails.
